# Files of the upstream busytex data packages that go into the galley-tex data package.
#
# Syntax (see scripts/build-tex.mjs):
#   pattern     include; relative to /texlive/texmf-dist unless it starts with a slash
#   !pattern    exclude (wins over every include)
#   dir/        a trailing slash means the whole directory tree
#   *  within a path segment, ** across segments
# Every include rule must match at least one file, so an upstream layout change fails the build.
#
# The Ubuntu packages (/texmf/texmf-dist) are merged onto /texlive/texmf-dist; where both provide
# a file, the /texlive copy is used. The elsarticle class and bst files come from tex/extra.
# The file list was derived from the files the engine opened while compiling the Quarto elsevier
# reference and the package test documents, widened to whole package directories.
